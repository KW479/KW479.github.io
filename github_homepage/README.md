# 个人主页源码（副本）

本目录是仓库根目录网站源码的完整副本，供离线查看与验收。

## 本地预览

**方式一：直接打开（最简单）**

双击 `index.html`，或把它拖进浏览器窗口即可。不需要服务器，不需要安装任何东西。

**方式二：起一个本地服务器（可选）**

想在真实 HTTP 环境下验证时，在本目录执行：

```bash
python -m http.server 8000
```

然后浏览器访问 <http://localhost:8000/>。没装 Python 也可以用 `npx serve .`。

## 文件清单

| 文件 | 说明 |

| `index.html` | 整站唯一文件，结构与样式全在里面 |
