## 设计说明

- 浅色简洁风格：米白底色（`#fcfcfa`）配深色文字（`#1a1a1a`），无装饰性图形和渐变
- 全部样式内联在 `index.html` 的 `<style>` 中，不依赖任何外部 CSS、JS、字体或图片
- 响应式：字号使用 `clamp()` 自适应，手机端自动收缩内边距
- 可访问性：语义化标签、`focus-visible` 焦点样式、`prefers-reduced-motion` 降级、支持 SVG 站点头像
